Fix “Validation failed: options are not unique” in a Shopify product CSV

Validation failed: options are not unique

What it means

Two rows that belong to the same product (same URL handle) have exactly the same option values — for example two variants that are both Medium / Black. Shopify can't create two identical variants, so the import stops for that product.

Common causes

  • A real duplicate: the same size/color combination listed twice, often after copying rows.
  • Two different products accidentally share one handle, so their variants are merged and collide.
  • Rows of the same product appear in two places in the file (for example after sorting by SKU), and the second block repeats option values from the first.
  • Values that look different to you but are equal to Shopify, such as Black and black, or a trailing space.

How to fix it

  1. Sort the sheet by the handle column so all rows of each product are together.
  2. Within each product, look for two rows with the same Option1/Option2/Option3 values and delete or correct one.
  3. If two different products share a handle, give one of them its own handle (letters, numbers and dashes only).
  4. Trim spaces and keep capitalisation consistent in option values.
