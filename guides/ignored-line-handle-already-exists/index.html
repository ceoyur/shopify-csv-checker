Fix “Ignored line … because handle already exists” and “did not contain product data”

Ignored line because handle already exists / did not contain product data

What it means

Shopify uses the handle to decide which rows belong to which product. A line is ignored when its handle clashes with another product, or when a product's rows have a handle but no product title.

Common causes

  • Two different products were given the same handle (for example both generated from the title “T-Shirt”).
  • A product's first row has a handle but an empty Title.
  • Rows with neither handle nor title — Shopify can't attach them to any product.
  • Handles with spaces or capital letters that you expected to be different from the cleaned-up version.

How to fix it

  1. Give every product a unique handle: lowercase letters, numbers and dashes only.
  2. Fill Title on the first row of each product.
  3. Remove or complete rows that have no handle and no title.
