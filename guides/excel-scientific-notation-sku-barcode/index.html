Excel changed my SKUs and barcodes to 8.90123E+11 — fix before importing to Shopify

SKU or barcode turned into 8.90123E+11 after editing in Excel

What it means

When Excel opens a CSV it guesses column types. Long numbers such as EAN/UPC barcodes or numeric SKUs become numbers, are shown as 8.90123E+11, and lose their last digits and leading zeros when the file is saved. Shopify then imports the broken values without any error.

Common causes

  • Opening the CSV by double-clicking it in Excel.
  • Saving the file after Excel has converted the column.

How to fix it

  1. Don't try to repair the scientific-notation values — the original digits are gone. Re-export the file from your store or supplier.
  2. Open CSVs in Excel via Data → From Text/CSV and set SKU and barcode columns to Text.
  3. Or edit product CSVs in Google Sheets, which keeps them as text more reliably.
