Fix Shopify CSV image errors: “error occurred while trying to download the image” and “getaddrinfo”

Validation failed: An error occurred while trying to download the image / getaddrinfo

What it means

Shopify downloads every image URL in the file during import. If the address is malformed or not a public, direct link to an image file, the download fails. The getaddrinfo error means the URL itself is wrong — Shopify couldn't even find the server.

Common causes

  • URLs without http:// or https:// (e.g. cdn.example.com/img.jpg).
  • Spaces in the file name or path.
  • Share links from cloud drives that open a preview page instead of the image.
  • Images behind a login or deleted from the server.
  • Image position values of 0 or text instead of 1, 2, 3…

How to fix it

  1. Use full https:// URLs and replace spaces with %20 (or rename the files).
  2. Open each failing URL in a private browser window — it should show only the image.
  3. Avoid file names ending in _small, _thumb or _medium; they're often low-resolution copies.
