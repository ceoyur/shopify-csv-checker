Shopify CSV import deleted or skipped variants without an error — causes and checks

Variants missing or deleted after a Shopify CSV import (no error shown)

What it means

Sometimes the import reports success but some variants are missing afterwards. Shopify builds each product from all rows that share a handle, so anything that changes how rows are grouped or how option values are read can drop or replace variants. Shopify's own documentation notes that changing an option value creates new variant IDs.

Common causes

  • Rows of one product are not next to each other in the file.
  • Two rows with the same option combination — one replaces the other.
  • Inch/foot quote marks or stray quotes in option values shift the cells after them.
  • Option values edited (even capitalisation) when you meant to update only prices or stock, which creates new variants instead of updating existing ones.
  • Rows missing an option value for an option the product uses.

How to fix it

  1. Export a backup before every import.
  2. Sort by handle and check each multi-option product for duplicates and missing values.
  3. When updating existing products, don't change option values unless you intend to.
  4. Test with 2–3 multi-option products first, then import the rest.
