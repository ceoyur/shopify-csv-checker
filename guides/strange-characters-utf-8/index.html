What it means

Shopify reads CSV files as UTF-8. If the file was saved in another encoding — Excel's plain “CSV (Comma delimited)” uses the Windows code page — characters like é, ’ or ° are read wrongly and show up as Ã©, â€™ or �.

Common causes

  • Saved from Excel as “CSV (Comma delimited)” instead of “CSV UTF-8”.
  • A supplier file in Windows-1252 or Latin-1 that was opened and re-saved.
  • Text that was already garbled once and then saved again — it can't be fixed by re-encoding.

  1. In Excel: File → Save As → CSV UTF-8 (Comma delimited).
