Fix “Option value provided for unknown options” when importing products to Shopify

Option value provided for unknown options

What it means

A row has a value in Option1 value (or Option2/Option3) but Shopify doesn't know which option it belongs to, because the product has no matching Option1 name. Shopify takes option names from the product's rows grouped by handle.

Common causes

  • The option name (e.g. Size) is missing on the product's first row.
  • A typo, capital letter or trailing space in the handle on one row makes Shopify treat that row as a new product — a product without option names.
  • Option2 values were added but the Option2 name column is empty.

How to fix it

  1. On the first row of each product, fill Option1 name (and 2/3 if used).
  2. Make sure every row of the product uses exactly the same handle.
  3. For products without variants, use Option1 name = Title and Option1 value = Default Title, or leave both empty.
